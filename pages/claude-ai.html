在 claude.ai 使用

想讓大家的手機看到同一份帳？照這頁做，五分鐘完成。

為什麼要用 claude.ai 版

直接打開這個網站時，帳本是本機模式：資料只存在自己的手機，朋友看不到。把同一個 App 放到 claude.ai 上變成 Artifact，就能使用 claude.ai 的共享資料庫，每個人在自己手機上記帳，大家即時看到同一份帳。

本機模式（這個網站）

  • 不用帳號、打開就能用
  • 資料只在這支手機
  • 可以匯出／匯入備份

claude.ai 版

  • 每個人都要有 claude.ai 帳號
  • 多支手機即時同步
  • 頭貼存在雲端

需要準備什麼

  • 一個可以建立 Artifact 的 claude.ai 帳號（用 claude.ai 的對話或 Claude Code 都可以）。
  • 這三個檔案：app/index.html、app/ledger.js、app/store.js。可以從 GitHub repo 下載，或直接把 repo 網址給 Claude。

步驟

  1. 打開 Claude，把上面三個檔案附上（或貼 repo 網址）。
  2. 貼上下面這段指令，讓 Claude 幫你發佈。
  3. 發佈完成後打開 Artifact，建立帳本、輸入成員。
  4. 用 Artifact 右上角的分享，輸入朋友的 email，權限選「編輯者」。

複製給 Claude 的指令

請把附上的 EatTogether 記帳 App 發佈成一個 claude.ai Artifact：
1. 主頁面用 app/index.html，ledger.js 和 store.js 當作同一個 Artifact 的附屬檔案一起發佈（路徑保持 ledger.js、store.js）。
2. capabilities 開啟：db、user、assets（都用預設設定）。
3. 不要修改計算邏輯和資料格式；只需要做發佈所需的最小調整。
4. 發佈後讀一次 members 和 entries 兩個集合，確認資料庫可以用。
5. 給我 Artifact 連結，並提醒我：分享時要邀請朋友 email 當「編輯者」，不要開公開連結。

分享時要注意

  • 不要開「公開連結」。開了之後，用 email 邀請的朋友就不能記帳。
  • 朋友也要登入 claude.ai 才能打開。
  • 頭貼可能只有你自己看得到（平台限制）；看不到時會顯示名字縮寫。

隱私：會不會看到別人的帳？

  • 每個 Artifact 都有自己獨立的資料庫。你發佈的那一份是全新、空的帳本，看不到作者或其他人的帳，別人也看不到你的。
  • 這個 repo 裡只有程式碼，沒有任何人的名字或帳務資料；教學截圖用的是虛構的「小明、小華、阿傑」。
  • Artifact 預設只有你看得到。只分享給一起吃飯的朋友，不要把自己的 Artifact 連結貼到公開的地方（社群、作業區、GitHub）。
  • 匯出的備份檔裡有名字和金額，傳給別人前想一下。
